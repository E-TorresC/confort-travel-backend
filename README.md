# CONFORT TRAVEL — Backend

API REST para el sistema interno de gestión y seguimiento
de ventas y viajes de CONFORT TRAVEL.

## Stack

- Java 21
- Spring Boot 4.1.1
- Maven
- Spring Web MVC
- Jakarta Bean Validation
- Lombok
- Spring Boot Actuator

## Ejecución

mvn spring-boot:run

## Testing

mvn test
